# Starli Run

A fan-made HTML5 Canvas browser game for the Soneium community's countdown to "The Next Chapter".
Help Starli, the Startale cat astronaut, fly through the portal that opens the next chapter.

- No build step, no dependencies
- Open `index.html` or play via GitHub Pages
- Team notes: see [`docs/GAME_DETAILS.md`](docs/GAME_DETAILS.md)
